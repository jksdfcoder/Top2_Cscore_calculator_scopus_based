# Interface decisions

The approved brief is an Operate surface: a plain, readable single-page workflow. Let headings, whitespace, alignment and actual data carry the page. Do not add a dashboard sidebar, marketing hero, gradients, ornamental cards or custom control system.

Use Nuxt UI controls with semantic colors, a light background, a restrained teal accent and the locally available system sans stack. Body text is 16px; numeric results use tabular numerals. Main content is bounded at 1120px. Related regions pair through container queries and stack when their container is narrow. Tables scroll within their region.

Show import, identity, recovery and results in reading order. Career and single-year summaries remain together. Warnings name the missing input and the next action. Color never carries status alone. Graphical data must have an equivalent table. Keep controls usable by keyboard, show focus and respect reduced motion.
