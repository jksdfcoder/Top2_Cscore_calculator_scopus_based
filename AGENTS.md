# Working on this repository

Read `HANDOFF.md`, `PRODUCT.md`, `DESIGN.md`, then the staged plan in `docs/plans/` before changing scope.

- Keep one page, standard Nuxt UI components, restrained layout and local-only personal data processing.
- Never commit real Scopus exports, account screenshots, cookies or institutional credentials. Fixtures must be synthetic.
- Never infer missing citations as zero. Unknown exclusion settings, unresolved matches and conflicting windows must block affected modes.
- Career uses received citations during 1996–2025, not lifetime totals or only publication-year filtering. Single-year uses citations received in 2025 across eligible publications.
- Do not confuse selected-author self-citation exclusion with all-author exclusion.
- Freeze version metadata with normalization and future cohorts. Field choice does not change the global c-score formula.
- Official published cohorts are selected lists; never label a percentile within those lists as a percentile of all researchers.
- Run unit tests, typecheck, static generation and browser tests after material changes. Private parity is opt-in and unavailable in ordinary CI.
